# Data Inside

Data Inside is een BI- en data-consultancy uit Zwolle, gespecialiseerd in data-oplossingen voor Nederlandse goededoelenorganisaties. Wij helpen fondsenwervers om met betrouwbare data betere beslissingen te nemen.

## Wat we doen

- **Data warehousing & ETL** — bouw en beheer van datawarehouses en ETL-pipelines (SQL Server, SSIS/ZappySys) die CRM-, campagne- en financiële data van onze klanten samenbrengen.
- **Power BI dashboards** — rapportage- en analysedashboards per fondsenwervingskanaal (Direct Mail, Face-to-Face, Telemarketing, Online, Major/Middle Donors) en marktbrede benchmarking.
- **Maatwerksoftware** — interne en klantgerichte tools (Laravel/PHP, Python/FastAPI) voor portals, planningstools en data-gedreven workflows.
- **Data-consultancy** — advies en ondersteuning bij datavraagstukken binnen de non-profitsector.

## Tech stack

- **Data & BI:** SQL Server, SSIS/ZappySys, Power BI, KNIME
- **Applicaties:** Laravel (PHP), Python (FastAPI, uv), SQLAlchemy/pyodbc
- **CRM-integraties:** Salesforce, Microsoft Dynamics/Engage
- **Infrastructuur:** Windows/IIS, GitHub Actions (CI/CD), Dependabot, Trivy (security scanning)
